## 1. 设置时长

- 主窗口表盘中央是 **时 : 分 : 秒** 三个输入框，可设置 `00:00:01` – `99:59:59`。
- 输入方式：
  - 直接键入数字；连续键入时保留最后两位（例如在分钟框依次输入 `1` `5` 得到 `15`），超出范围自动取上限；
  - `↑` / `↓` 每次 ±1，按住 `Shift` 每次 ±10，超出范围时循环；
  - 鼠标悬停在输入框上滚动滚轮调整；
  - 六个常用时长按钮：1 / 3 / 5 / 10 / 25 / 60 分钟，当前时长与某个按钮一致时该按钮高亮。
- 时长为 0 时点击「开始」，按钮上方会显示错误提示并把焦点移到分钟输入框。
- 每次开始倒计时都会记住该时长，下次启动程序自动填入（默认 25 分钟）。

## 2. 倒计时

- 主按钮随状态变化：**开始 → 暂停 → 继续**；计时中和暂停时出现「停止」按钮。
- 表盘进度环随剩余时间收缩；中央显示：
  - 状态文字（设置时长 / 倒计时中 / 已暂停 / 时间到）；
  - 剩余时间（时长不足 1 小时显示 `MM:SS`，否则 `HH:MM:SS`，秒数向上取整）；
  - 当前轮次与预计结束时刻，例如「第 2 轮 · 14:35 结束」。
- 「停止」会结束本次计时、清零轮数，并把输入框恢复为刚才的时长，方便直接再次开始。
- 计时在 Rust 后台线程中基于单调时钟进行：窗口隐藏、最小化或被其他窗口遮挡都不影响准确性；
  空闲时计时线程完全阻塞，运行时每秒只唤醒一次。

## 3. 时间到提醒与重复倒计时

- 倒计时结束时：
  - 弹出居中、置顶的「时间到」提醒窗口，任务栏图标闪烁；
  - 若开启了提示音，循环播放 Windows 声音方案中的「闹钟」声音，直到用户响应或满 1 分钟
    （系统未配置闹钟声音时退回为播放一次「感叹号」提示音）；
  - 托盘提示变为「时间到！」，主窗口也切换到「时间到」状态。
- 提醒窗口中的操作：
  - **重置**（默认焦点，可直接按 `Enter`）：以相同时长立即开始下一轮倒计时，已完成轮数累计；
  - **停止** / 按 `Esc` / `Alt+F4` 关闭弹窗：结束本次计时，回到设置状态，轮数清零。
- 主窗口在「时间到」状态下同样提供「重置」和「停止」按钮，托盘菜单中的主操作也会变为「重置」。
- 用户做出选择后提醒窗口会被销毁，不额外占用内存。

## 4. 后台驻留

- 程序启动后在系统托盘常驻图标，鼠标悬停显示当前状态和剩余时间（每秒更新）。
- 单击托盘图标打开主窗口；右键菜单：
  - 显示主窗口
  - 开始 / 暂停 / 继续 / 重置（随状态变化；空闲时按上次时长开始）
  - 停止（空闲时禁用）
  - 退出
- 关闭主窗口时默认隐藏到托盘、继续计时；可在设置中改为「关闭即退出」，主窗口底部的提示文字会随之变化。
- 单实例：程序已在运行时再次启动，只会唤起已有的主窗口。

## 5. 设置

点击主窗口右上角的设置按钮打开设置面板（`Esc` 或左上角返回按钮关闭）：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 提示音 | 开 | 时间到时循环播放系统闹钟声，最长 1 分钟；响铃时关闭此项会立即停止响铃 |
| 关闭窗口时隐藏到托盘 | 开 | 关闭后程序在后台继续计时 |
| 开机自动启动 | 关 | 写入当前用户的注册表启动项，登录后带 `--hidden` 参数静默驻留托盘 |

- 设置面板底部提供「退出程序」按钮并显示当前版本号。
- 设置保存在 `%APPDATA%\io.github.whr819987540.countdowntimer\settings.json`（开机自启动状态以注册表为准，不写入该文件）。

## 6. 界面与无障碍

- 跟随 Windows 浅色 / 深色主题；所有文字对比度满足 WCAG AA（≥ 4.5:1）。
- 全键盘可操作，焦点环清晰可见；屏幕阅读器可读出状态变化、计时器和按钮名称。
- 系统开启「减少动画」时，进度环过渡、弹窗铃铛摆动、设置面板滑入等动效全部关闭。
- 状态不只靠颜色区分：每个状态都有对应的文字说明。

### 键盘操作

| 位置 | 按键 | 作用 |
| --- | --- | --- |
| 时长输入框 | 数字键 | 输入（保留最后两位） |
| 时长输入框 | `↑` / `↓`（`Shift` 加速） | 调整数值 |
| 时长输入框 | `Enter` | 开始倒计时 |
| 主窗口（焦点不在控件上） | `Space` | 执行主操作（开始 / 暂停 / 继续 / 重置） |
| 设置面板 | `Esc` | 关闭设置面板 |
| 提醒弹窗 | `Enter` | 重置（再来一轮） |
| 提醒弹窗 | `Esc` | 停止 |

## 7. 安装与更新

- 安装包为 NSIS 格式（约几 MB），按当前用户安装，无需管理员权限；
  依赖 WebView2（Windows 11 自带，Windows 10 安装时自动下载）。
- 每次向 `main` 分支推送并通过全部检查后，GitHub Actions 自动构建并覆盖 `rolling` 发布；
  版本号为 `0.1.<构建序号>`，直接运行新安装包即可覆盖升级。

## 已知限制

- 安装包未做代码签名，首次运行可能出现 SmartScreen 提示。
- 仅提供 Windows x64 安装包。
- 未针对电脑睡眠 / 休眠期间的计时做专门处理；需要跨越睡眠的提醒时请保持电脑唤醒。
- 程序内没有自动更新检查，需要手动下载新的安装包。
