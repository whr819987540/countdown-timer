## 1. 设置时长

- 主窗口顶部的分段控件用于切换计时模式：**自定义时长**（本节）或 **20-20-20 护眼**（见第 4 节）。
  只能在未开始计时时切换（可用 `←` / `→` 键），程序会记住上次选择的模式。
- 主窗口表盘中央是 **时 : 分 : 秒** 三个输入框，可设置 `00:00:01` – `99:59:59`。
- 输入方式：
  - 直接键入数字；连续键入时保留最后两位（例如在分钟框依次输入 `1` `5` 得到 `15`），超出范围自动取上限；
  - `↑` / `↓` 每次 ±1，按住 `Shift` 每次 ±10，超出范围时循环；
  - 鼠标悬停在输入框上滚动滚轮调整；
  - 六个常用时长按钮：1 / 3 / 5 / 10 / 25 / 60 分钟，当前时长与某个按钮一致时该按钮高亮。
- 时长为 0 时点击「开始」，按钮上方会显示错误提示并把焦点移到分钟输入框。
- 每次开始倒计时都会记住该时长，下次启动程序自动填入（默认 25 分钟）。

## 2. 倒计时

- 主按钮随状态变化：**开始 → 暂停 → 继续**；计时中和暂停时出现「停止」按钮。
- 表盘进度环随剩余时间收缩；中央显示：
  - 状态文字（设置时长 / 倒计时中 / 已暂停 / 时间到）；
  - 剩余时间（时长不足 1 小时显示 `MM:SS`，否则 `HH:MM:SS`，秒数向上取整）；
  - 当前轮次与预计结束时刻，例如「第 2 轮 · 14:35 结束」。
- 「停止」会结束本次计时、清零轮数，并把输入框恢复为刚才的时长，方便直接再次开始。
- 计时在 Rust 后台线程中基于单调时钟进行：窗口隐藏、最小化或被其他窗口遮挡都不影响准确性；
  空闲时计时线程完全阻塞，运行时每秒只唤醒一次。

### 悬浮窗

- 开始计时后（从主窗口、托盘或键盘开始均可），主窗口自动隐藏，屏幕右上角出现一个约 240×64 的悬浮窗：
  始终置顶、不占任务栏，显示进度环、剩余时间和状态（倒计时中 / 已暂停 / 时间到 / 专注中 / 远眺休息中 …）。
- 悬浮窗上的按钮：
  - **主操作**：暂停 / 继续；时间到时变为重置、开始休息或下一轮（与主窗口的主按钮一致）；
  - **展开**：关闭悬浮窗并打开主窗口。单击托盘图标或托盘菜单「显示主窗口」效果相同。
- 按住悬浮窗任意空白处可拖动；程序会记住拖到的位置，下次沿用（该位置已不在任何屏幕内时回到右上角）。
- 计时停止、回到空闲时悬浮窗自动关闭；如果主窗口是被悬浮窗替换掉的，会同时恢复显示。
- 计时中主窗口顶栏出现「缩为悬浮窗」按钮，可随时再缩回悬浮窗。
- 不需要悬浮窗时，在设置中关闭「开始计时后缩为悬浮窗」；用 `Alt+F4` 关闭悬浮窗后计时在托盘中继续。

## 3. 时间到提醒与重复倒计时

- 倒计时结束时：
  - 弹出居中、置顶的「时间到」提醒窗口，任务栏图标闪烁；
  - 若开启了提示音，循环播放 Windows 声音方案中的「闹钟」声音，直到用户响应或满 1 分钟
    （系统未配置闹钟声音时退回为播放一次「感叹号」提示音）；
  - 托盘提示变为「时间到！」，主窗口也切换到「时间到」状态。
- 提醒窗口中的操作：
  - **重置**（默认焦点，可直接按 `Enter`）：以相同时长立即开始下一轮倒计时，已完成轮数累计；
  - **停止** / 按 `Esc` / `Alt+F4` 关闭弹窗：结束本次计时，回到设置状态，轮数清零。
- 主窗口在「时间到」状态下同样提供「重置」和「停止」按钮，托盘菜单中的主操作也会变为「重置」。
- 用户做出选择后提醒窗口会被销毁，不额外占用内存。

## 4. 20-20-20 护眼模式

依据「每用眼 20 分钟，看向 6 米（20 英尺）外的物体 20 秒」的护眼法则，在主窗口顶部切换到 **20-20-20 护眼** 即可进入。
该模式时长固定，表盘显示 `20:00`，常用时长按钮换成一段简短说明。

1. 点击「开始」：开始 **20 分钟专注** 倒计时，状态为「专注中」，下方显示预计休息时刻，例如「第 1 轮 · 14:20 休息」。
2. 专注结束：弹出置顶提醒「该休息眼睛了」（可选响铃、任务栏闪烁），此时 **不会自动开始休息**：
   - **开始休息**（默认焦点，`Enter`）：开始 **20 秒远眺休息** 倒计时；
   - **停止** / `Esc` / `Alt+F4`：结束本次护眼计时。
3. 休息期间提醒弹窗保持打开，以绿色眼睛图标和大号数字显示剩余秒数，提示「看向 6 米（20 英尺）外的物体，放松眼睛」；
   主窗口同步显示「远眺休息中」和绿色进度环。休息期间同样可以暂停 / 继续 / 停止。
4. 休息结束：弹窗切换为「休息结束」并再次提醒（响铃、置前），此时 **不会自动开始下一轮**：
   - **下一轮**（默认焦点，`Enter`）：开始下一个 20 分钟专注；
   - **停止** / `Esc`：结束本次护眼计时。
- 轮数只统计完成的专注段；停止后轮数清零，回到「准备专注」状态。
- 主窗口在「该休息眼睛了」/「休息结束」状态下同样提供「开始休息」/「下一轮」和「停止」按钮；
  托盘菜单的主操作会相应变为「开始休息」/「开始下一轮」，托盘提示显示「20-20-20 · 专注剩余 12:34」等。
- 切换到护眼模式不会改变自定义时长，切回后仍是原来的时长。

## 5. 后台驻留

- 程序启动后在系统托盘常驻图标，鼠标悬停显示当前状态和剩余时间（每秒更新）。
- 单击托盘图标打开主窗口（悬浮窗打开时会先关闭它）；右键菜单：
  - 显示主窗口
  - 开始 / 暂停 / 继续 / 重置 / 开始休息 / 开始下一轮（随状态变化；空闲时按当前模式和上次时长开始）
  - 停止（空闲时禁用）
  - 退出
- 关闭主窗口时默认隐藏到托盘、继续计时；可在设置中改为「关闭即退出」，主窗口底部的提示文字会随之变化。
- 单实例：程序已在运行时再次启动，只会唤起已有的主窗口。

## 6. 设置

点击主窗口右上角的设置按钮打开设置面板（`Esc` 或左上角返回按钮关闭）：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 提示音 | 开 | 时间到时循环播放系统闹钟声，最长 1 分钟；响铃时关闭此项会立即停止响铃 |
| 开始计时后缩为悬浮窗 | 开 | 见第 2 节「悬浮窗」；关闭后计时期间保持主窗口不变 |
| 关闭窗口时隐藏到托盘 | 开 | 关闭后程序在后台继续计时 |
| 开机自动启动 | 关 | 写入当前用户的注册表启动项，登录后带 `--hidden` 参数静默驻留托盘 |
| 自动检查更新 | 开 | 每 6 小时检查一次新版本，只提示、不自动安装（见第 8 节）；打开时立即检查一次 |

- 设置面板中显示当前版本号与更新状态，并提供「检查更新」/「立即更新」按钮；底部是「退出程序」按钮。
- 设置保存在 `%APPDATA%\io.github.whr819987540.countdowntimer\settings.json`，其中还记录上次使用的时长、计时模式和悬浮窗位置
  （开机自启动状态以注册表为准，不写入该文件）。

## 7. 界面与无障碍

- 跟随 Windows 浅色 / 深色主题；所有文字对比度满足 WCAG AA（≥ 4.5:1）。
- 适配高缩放比例的屏幕（如 1080p 屏幕设为 175%）：窗口高于屏幕可用区域时，自动缩小并在任务栏以外的区域居中，
  界面整体等比缩小（最小 80%）以完整显示所有按钮；屏幕实在过小时可滚动查看。
- 全键盘可操作，焦点环清晰可见；屏幕阅读器可读出状态变化、计时器和按钮名称。
- 系统开启「减少动画」时，进度环过渡、弹窗铃铛摆动、设置面板滑入、模式切换等动效全部关闭。
- 状态不只靠颜色区分：每个状态都有对应的文字说明。

### 键盘操作

| 位置 | 按键 | 作用 |
| --- | --- | --- |
| 时长输入框 | 数字键 | 输入（保留最后两位） |
| 时长输入框 | `↑` / `↓`（`Shift` 加速） | 调整数值 |
| 时长输入框 | `Enter` | 开始倒计时 |
| 模式切换 | `←` / `→` | 在「自定义时长」与「20-20-20 护眼」之间切换（仅未开始时） |
| 主窗口（焦点不在控件上） | `Space` | 执行主操作（开始 / 暂停 / 继续 / 重置 / 开始休息 / 下一轮） |
| 设置面板 | `Esc` | 关闭设置面板 |
| 提醒弹窗 | `Enter` | 重置（再来一轮）；护眼模式下为开始休息 / 下一轮 |
| 提醒弹窗 | `Esc` | 停止 |

## 8. 安装与更新

- 安装包为 NSIS 格式（约几 MB），按当前用户安装，无需管理员权限；
  依赖 WebView2（Windows 11 自带，Windows 10 安装时自动下载）。
- 每次向 `main` 分支推送并通过全部检查后，GitHub Actions 自动构建并覆盖 `rolling` 发布；
  版本号为 `0.1.<构建序号>`，直接运行新安装包即可覆盖升级。

### 自动更新

- 程序启动约 10 秒后检查一次，之后每 6 小时检查一次（可在设置中关闭「自动检查更新」）；
  设置面板中的「检查更新」可随时手动检查。检查走系统代理设置。
- 发现新版本时 **只提示，不会自动安装**：
  - 主窗口底部出现「发现新版本 x.y.z，点击更新」；
  - 托盘菜单「退出」上方出现「更新到 x.y.z」；
  - 设置面板中按钮变为「立即更新」。
- 点击更新后下载安装包并显示进度，下载完成后用内置公钥 **校验签名**（同时核对签名中记录的版本号，
  防止用旧版本安装包冒充新版本），校验通过才运行安装程序；
  安装程序以无需操作的进度窗口完成安装，随后程序自动重新启动并显示主窗口。
- 安装会重启程序，因此 **计时进行中不能更新**（提示变为「停止计时后可更新」）；若下载期间开始了计时，安装会自动取消。
- 检查失败（如断网）时定时检查静默跳过，手动检查会在设置面板中提示失败原因。
- 自动更新从首个带更新功能的版本开始生效；更早的版本需要手动下载安装一次。

## 已知限制

- 安装包未做代码签名，首次运行可能出现 SmartScreen 提示。
- 仅提供 Windows x64 安装包。
- 未针对电脑睡眠 / 休眠期间的计时做专门处理；需要跨越睡眠的提醒时请保持电脑唤醒。
